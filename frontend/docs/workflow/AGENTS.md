# 프론트엔드 AI 업무 시작점

[공통 AI 작업 지침](../../../AGENTS.md)과 [공통 문서 운영 기준](../../../project/documentation.md)을 따릅니다. 파트별 업무 절차와 업무 스킬은 담당 PL이 관리합니다.

## 요청별 참고 문서

| 요청 | 공용 스킬 또는 문서 |

필요한 단계에서 시작합니다. 파트별 상세 기준과 업무 스킬은 이번 요청에 필요한 경우에만 추가로 확인합니다.

- 실제 업무 원본과 기록은 필요할 때 지정합니다. 현재는 위치나 도구 연동을 정하지 않습니다.
- 이번 요청에 필요한 문서와 스킬을 선택합니다. 단순 수정에 전체 명세·기록·스킬 절차를 요구하지 않습니다.
- 기획서와 향후 Redmine의 업무 기록은 각 원본을 기준으로 확인합니다. 이곳에는 업무 절차와 기록 기준을 두고, 이슈 상세와 진행 상태를 별도 확정본으로 복제하지 않습니다.
- AI의 검토 결과를 정책 확정이나 업무 승인으로 처리하지 않습니다. 원본과 기록을 변경할 때는 요청 범위와 권한을 확인합니다.
- 결과에는 변경 내용·적용 근거·실제 검증 결과·미확인 사항·다음 작업을 작업 규모에 맞춰 정리합니다.
- 사람용 업무 안내와 필요한 업무 스킬·보조 도구는 실제 내용이 생길 때 담당 PL이 추가합니다.
