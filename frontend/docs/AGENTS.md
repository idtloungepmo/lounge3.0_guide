# 프론트엔드 문서 작업 지침

[파트 작업 지침](../AGENTS.md)과 [공통 문서 운영 기준](../../project/documentation.md)을 따릅니다. 문서 내용과 세부 구성은 담당 PL이 관리합니다.

- docs/README.md와 index.html은 문서 안내, guides/는 상세 기준, ai/는 핵심 요약, workflow/는 업무 절차·스킬·기록 기준을 관리합니다. 실제 내용이 생길 때 문서를 추가합니다.
- 가이드와 안내는 Markdown 원본을 먼저 수정하고 HTML에 반영합니다. 기획서·계약·소스·업무 기록은 각 원본을 유지합니다.
- 한국어 문서는 [공용 글쓰기 스킬](../../skills/guides/korean-work-writing/SKILL.md)과 공통 용어를 적용합니다. 같은 내용의 Markdown과 HTML은 제목·용어·의미를 맞춥니다.
- HTML은 [공통 템플릿](../../templates/README.md)과 [문서 자원](../../project/assets.md)을 사용합니다. 복사한 파일의 위치에 맞춰 자원과 내부 링크의 상대 경로를 조정합니다.
- 문서 상단에는 종류·제목·설명을, 하단에는 문서명만 표시합니다. 번호 있는 h2와 공통 절 이동 메뉴를 사용하고 수동 목차를 중복해서 만들지 않습니다.
- 작업에 필요한 원본만 읽고 같은 내용의 Markdown과 HTML을 중복해서 읽지 않습니다. 요약이 부족하거나 충돌하면 해당 원본을 확인합니다.
- 링크·HTML 구조·자원 경로·원본과 HTML의 내용 일치를 확인합니다. 화면을 변경하면 가능한 범위에서 데스크톱·모바일 화면을 확인합니다. 수행하지 못한 확인은 완료로 표시하지 않습니다.
- 업무에 필요한 문서·스킬 선택과 작업 기록은 [AI 업무 시작점](workflow/AGENTS.md)을 참고합니다.
