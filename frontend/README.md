# 프론트엔드 안내

이 폴더는 프론트엔드 저장소 안내와 하네스·가이드의 기본 구조 예시입니다. 실제 파트 공통은 담당 PL이 별도 저장소에서 관리합니다. 이곳에 실제 파트 문서의 별도 확정본을 만들지 않습니다.

**파트 저장소:** [lounge-docs](https://github.com/minsukong/lounge-docs)

프로젝트 공통 → 파트 공통 → 개인 하네스의 관계를 따릅니다. 작업자는 각자의 AI·하네스를 사용하면서 [프로젝트 공통](../AGENTS.md)과 실제 파트 저장소의 지침을 함께 확인합니다.
