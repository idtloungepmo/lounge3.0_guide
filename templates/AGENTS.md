# 공통 HTML 템플릿 지침

- [공통 문서 운영 기준](../project/documentation.md)과 [사용법](README.md)을 따릅니다. 이 폴더는 복사용 템플릿을 관리하며 실제 파트 문서는 파트 docs 또는 실제 문서 저장소에 둡니다.
- overview.md와 overview.html은 사람용 시작 페이지, document.md와 document.html은 상세 문서의 원본·표현 예시입니다. Markdown을 먼저 고치고 HTML을 맞춥니다.
- header → main/section → footer 구성과 번호 있는 h2를 사용합니다. Header는 종류·제목·설명, Footer는 문서명만 둡니다. 날짜·버전·Draft 표시와 수동 목차를 일괄 추가하지 않습니다.
- 공통 CSS·JS는 assets 원본을 참조합니다. 복사 위치에 맞춰 assets·홈·Markdown 원본·업무 자료의 상대 링크를 조정합니다.
- 문서 내용·상세 목차·파트별 업무와 스킬은 담당 PL이 관리합니다. 예시를 확정 기준이나 필수 문서 목록으로 취급하지 않습니다.
- 변경 시 원본·HTML 내용 일치, 링크·구조·공통 자원 연결을 확인하고 가능한 범위에서 넓은 화면·좁은 화면을 확인합니다.

- 한국어 제목·설명·예시는 [공용 글쓰기 스킬](../skills/guides/korean-work-writing/SKILL.md)을 적용합니다. 제목은 내용을 바로 알 수 있게, 본문은 차분한 ‘합니다’체로 작성합니다.
