02. 템플릿 사용 순서

  1. 원하는 파일을 자기 파트에 복사합니다. 예: planning/docs/index.html 또는 planning/docs/guides/주제.html. 대응 Markdown 원본도 함께 둡니다.
  2. Markdown 원본에 내용을 작성한 뒤 HTML의 제목·설명·본문·링크를 맞춥니다.
  3. body의 data-part에 해당 파트를 지정합니다. 기획 planning / 디자인 design / 프론트엔드 frontend / 백엔드 backend.
  4. 파트 docs 바로 아래는 ../../assets/, docs/guides 바로 아래는 ../../../assets/를 연결합니다. 홈과 원본 링크도 조정합니다.
  5. 파트 AGENTS.md에 문서 위치와 참고할 상황을 안내하고, 사람용 목차에도 링크를 추가합니다.

템플릿의 예시 내용은 확정된 프로젝트 기준이 아닙니다. 세부 폴더와 문서는 실제 내용이 생길 때 추가합니다.

03. 공통 문서 자원과 기록 양식

글꼴·표·반응형·인쇄는 공통 테마, 파트 구분은 공통 색상, 문서 구성은 document.css를 사용합니다. CSS·JS를 각 파트에 복제하지 않습니다.

  • 공통 문서 자원 파일과 연결 순서
  • 복사·경로·문서 원본 관리 안내
  • 협의·결정·인수인계 기록에 넣을 항목
  • 공통 문서 운영 안내
  • 공용 글쓰기 스킬
