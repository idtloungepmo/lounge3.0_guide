# 디자인 업무 스킬 관리 지침

업무 스킬의 종류·내용·추가·수정·사용 절차는 담당 PL이 관리합니다. 업무에 필요한 스킬을 선택해서 사용합니다.

- 반복 업무에 지침이 필요하면 스킬명/SKILL.md를 추가합니다. 실제 필요가 없는 스킬을 미리 만들지 않습니다.
- 스킬이 생기면 이 안내에 사용 조건과 경로를 추가하고 상위 workflow/AGENTS.md의 요청별 안내에서 참조합니다.
- 스킬에는 목적·사용 조건·필요한 원본·작업 방법·결과 정리 방법을 작성합니다. 공통 기준은 참조하고 본문을 반복 복사하지 않습니다.
- 특정 AI 제품이나 자동 호출 기능을 전제하지 않습니다. 필요한 SKILL.md를 직접 읽어서도 사용할 수 있게 작성합니다.
- 원본을 먼저 수정합니다. 도구별 복사본이 필요하면 원본과의 관계와 갱신 방법을 명시합니다.
- 스킬 사용으로 요청 범위나 승인 권한이 확대되지는 않습니다. 검토·수정·외부 등록을 구분합니다.

## 공용 글쓰기 스킬

한국어 문서를 작성하거나 문체를 수정할 때는 [korean-work-writing](../../../../skills/guides/korean-work-writing/SKILL.md)을 적용합니다. 파트별로 복사하지 않고 공용 원본을 참조합니다. 일반 채팅 말투에는 적용하지 않습니다.

[AI 업무 시작점](../AGENTS.md) · [공통 문서 운영 기준](../../../../project/documentation.md)

## 원본 스킬 선택과 연결

맷 포코크 등 원본 스킬과 필요한 하위 스킬·참고 파일을 확인하고, 파트 PL이 실제 업무에 맞는 사용 조건과 연결 방법을 정합니다. 원본 기준 버전과 프로젝트·파트의 적용 기준을 함께 관리합니다. [파트별 워크플로우 구성 안내](../../../../collaboration/workflow.md)를 참고합니다.
