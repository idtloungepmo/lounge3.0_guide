# 파트 간 계약 확인 항목

기능별로 필요한 항목만 적용합니다. 이 문서는 계약 내용이나 특정 구현 방식을 확정하지 않습니다. 기존 명세가 있으면 원본 링크·버전과 차이만 연결합니다.

| 경계 | 확인할 내용 |
| --- | --- |
| 기획 ↔ 디자인 | 요구사항·화면 ID, 흐름·상태·문구·권한, 환경 차이, 검수 기준 |
| 디자인 ↔ 프론트엔드 | 노드·버전, 컴포넌트·variant·토큰, 입력·포커스·반응형, 상태 |
| 프론트엔드 ↔ 백엔드 | 요청·응답·오류, 인증·권한, 업무 상태, 시간·금액 등 값의 의미, 재시도·중복 처리 |
| 웹 ↔ Flutter | 환경 정보, 기능·메시지 형식, 준비 시점, 성공·실패·취소, 복귀·뒤로가기, 플랫폼별 지원 |
| 백엔드 ↔ 외부 시스템 | 제공·소비 책임, 인증·데이터, 타임아웃·재시도, 중복·정합성, 장애·복구 |
| 개발 ↔ 검수·운영 | 대상 버전·환경·계정, 완료 조건, 실제 결과, 배포·전환·복구 |

## 계약 기록에 필요한 정보

계약 원본 / 적용 기능·플랫폼 / 제공·소비 영역 / 버전·상태 / 관리 담당·결정권자 / 미정 / 관련 결정 / 검증 근거.

변경 시 기존 소비자의 호환성, 영향받는 데이터·업무, 순차 반영 여부, 테스트·전환 책임을 확인합니다.

## 실제 계약 확인

API·인증·결제·Native Bridge의 세부 내용은 해당 계약 원본에서 확인합니다. 미정과 미확인을 구분하고, 예제 요청·응답을 승인된 계약처럼 추가하지 않습니다.
