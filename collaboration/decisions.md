# 미정·충돌·결정 관리

이 문서는 질문·문제·결정을 정리하는 공통 기준입니다. 실제 기록은 지정된 업무 원본에서 관리합니다. 향후 Redmine을 사용하면 지정된 이슈를 기준으로 확인하고, 이 문서에 이슈 상세를 별도 확정본으로 복제하지 않습니다.

## 상태와 처리

- 미확인: 자료 위치·접근 또는 사실 확인이 필요함.
- 결정 필요: 선택·정책·계약 합의가 필요함.
- 제안: 검토할 선택지와 영향이 정리됨.
- 확정: 결정권자의 확인과 적용 범위·근거가 기록됨.
- 반영 중·반영 완료: 관련 원본·구현·검증의 실제 반영 상태.
- 대체됨: 후속 결정과 이전 이력을 연결함.

결정 확정과 구현·검증 완료는 별도로 기록합니다. 상태 이름은 기존 팀 도구와 맞춰도 됩니다.

## 기록할 항목

식별 ID·제목 / 발견 위치·버전 / 질문·충돌 / 선택지·영향 / 현재 가능한 작업·영향받는 작업 / 결정권자·진행 담당 / 목표일 또는 미정 / 답변·근거·결정일 / 적용 범위 / 변경할 원본·작업 / 검증·후속 결정.

충돌은 각 자료의 실제 문구·범위·기준일을 비교합니다. 최근 파일, 화면 캡처 또는 현재 코드 한쪽만 보고 확정하지 않습니다.

## 자료 관리

실제 자료와 작업 기록의 위치는 추후 정리합니다. 현재는 기록 기준만 둡니다.
