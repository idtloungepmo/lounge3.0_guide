# 기획·요구 검토

## 역할과 공통 기준

이 스킬은 실제 프로젝트의 기획·설계·소스 작업에 사용하는 공통 방법입니다. 기획·요구의 누락이나 충돌을 검토할 때 선택합니다. [공통 AI 작업 지침](../../../AGENTS.md)을 따르고, 파트별 상세 기준·업무 스킬은 필요한 경우에만 추가로 확인합니다.

공통 가이드·브리핑 자체를 작성하거나 다듬는 작업은 [가이드 작성 스킬](../../guides/AGENTS.md)을 사용합니다.

## 확인할 입력

- 대상 기능·검토 목적·확인할 범위와 제공된 기획서 또는 문제 설명을 확인합니다.
- 관련 원본·이전 결정·기존 코멘트에서 이미 답이 있는지 먼저 찾습니다. 이번 질문과 관련된 부분만 읽습니다.
- 자료를 읽지 못한 상태와 자료에 내용이 없는 상태를 구분합니다. 실제 확인한 파일·화면·슬라이드·버전 등 근거를 남깁니다.

## 작업 방법

1. 사용 목적·시작 조건·주요 행동·결과와 필요한 예외를 확인합니다.
2. 확인된 요구, 결정이 필요한 정책·계약, 구현 방법에 관한 제안, 미확인 자료를 구분합니다.
3. 질문에는 실제 상황·결정할 내용·관련 파트·작업 영향을 정리합니다. 확인된 답을 반복해서 묻지 않습니다.
4. 기획 보완이 필요하면 [사람·AI 공통 코멘트 양식](../../../collaboration/planning-comments.md)의 필요한 항목을 사용합니다. 한 코멘트에는 함께 결정할 주제 하나를 담습니다.
5. 초안 요청은 초안으로 제공합니다. 등록 요청은 대상·범위·도구·권한을 확인해 처리하고 실제 결과를 남깁니다. 이 스킬을 선택했다는 이유만으로 구현·등록·정책 확정을 진행하지 않습니다.

## 받을 결과

확인된 요구와 근거 / 결정할 질문 / 기획서 반영 요청 / 관련 파트와 작업 영향 / 진행 가능한 범위 / 미확인 사항과 다음 작업을 정리합니다. 담당은 확인된 경우에만 지정합니다. 코멘트는 초안·등록 성공·등록 실패를 구분합니다.


## 다음 작업과 기록

필요한 단계에서 시작합니다. 모든 스킬을 순서대로 실행하지 않습니다. 실제 결정·작업·이슈 상세는 지정된 원본에서 관리하고, 공통 가이드에는 복제하지 않습니다. 작업을 재개할 때는 이전 결과·미확인 사항·다음 작업부터 확인합니다.
