# 결과 검토·인수인계

## 역할과 공통 기준

이 스킬은 실제 프로젝트의 기획·설계·소스 작업에 사용하는 공통 방법입니다. 결과의 누락·문제와 완료 근거를 확인할 때 선택합니다. [공통 AI 작업 지침](../../../AGENTS.md)을 따르고, 파트별 상세 기준·업무 스킬은 필요한 경우에만 추가로 확인합니다.

공통 가이드·브리핑 자체를 작성하거나 다듬는 작업은 [가이드 작성 스킬](../../guides/AGENTS.md)을 사용합니다.

## 확인할 입력

- 검토 대상·범위·비교 기준과 요구·완료 조건의 근거를 확인합니다.
- 실제 변경과 관련 원본·결정·검증 결과를 확인합니다. 작성자의 완료 보고와 직접 확인한 근거를 구분합니다.
- 자료나 환경이 부족하면 확인하지 못한 범위를 남깁니다. 검토 범위를 요청 없이 전체 프로젝트로 넓히지 않습니다.

## 작업 방법

1. 변경 목적·요구·완료 조건과 실제 결과를 대조합니다.
2. 문서의 의미·조건·원본 일치, 디자인의 필요한 상태·사용 흐름, 코드의 실패 조건·소비자 영향 중 관련된 항목을 확인합니다.
3. 확인된 문제에는 위치·발생 조건·영향·수정 방향을 제시합니다. 미정 정책은 질문으로, 자료 부족은 검증 한계로 구분합니다.
4. 개선 제안과 필수 수정 사항을 구분합니다. 확인된 문제가 없으면 없다고 보고하고 억지로 지적하지 않습니다.
5. 검토만 요청받았으면 임의 수정하지 않습니다. 후속 수정 요청이 있으면 해당 범위에서 작성·수정·검증 스킬을 적용합니다.
6. 인수인계에는 현재 결과·미확인 사항·필요한 판단·다음 작업을 남깁니다. AI의 검토 결과를 담당자의 최종 승인이나 외부 상태 변경으로 처리하지 않습니다.

## 받을 결과

검토 범위와 근거 / 확인된 문제·영향·수정 방향 / 결정할 질문 / 개선 제안이 있는 경우 해당 내용 / 실제 확인한 검증과 한계 / 완료 조건별 판단 / 다음 작업을 정리합니다.


## 다음 작업과 기록

필요한 단계에서 시작합니다. 모든 스킬을 순서대로 실행하지 않습니다. 실제 결정·작업·이슈 상세는 지정된 원본에서 관리하고, 공통 가이드에는 복제하지 않습니다. 작업을 재개할 때는 이전 결과·미확인 사항·다음 작업부터 확인합니다.
