# 설계·작업 계획

## 역할과 공통 기준

이 스킬은 실제 프로젝트의 기획·설계·소스 작업에 사용하는 공통 방법입니다. 작업 방법·범위·완료 조건을 정할 때 선택합니다. [공통 AI 작업 지침](../../../AGENTS.md)을 따르고, 파트별 상세 기준·업무 스킬은 필요한 경우에만 추가로 확인합니다.

공통 가이드·브리핑 자체를 작성하거나 다듬는 작업은 [가이드 작성 스킬](../../guides/AGENTS.md)을 사용합니다.

## 확인할 입력

- 목표·대상·요구와 결정 근거, 기존 문서·디자인·소스 중 작업에 필요한 원본을 확인합니다.
- 관련 파트와 주고받는 정보, 현재 제약, 선행 조건과 미정 사항을 확인합니다.
- 자료가 없으면 제공된 근거와 미확인 범위를 구분합니다. 없는 저장소·문서·정책을 가정하지 않습니다.

## 작업 방법

1. 이번 목표와 범위, 포함하지 않는 작업을 요청에 맞춰 정리합니다.
2. 현재 상태와 변경할 내용을 비교합니다. 실제 선택이 필요한 대안이 있으면 이유와 영향을 설명합니다.
3. 결과를 확인할 수 있는 작업 단위로 나누고 선행 조건·관련 파트·완료 조건을 정합니다. 작은 수정은 별도 작업 분해를 강제하지 않습니다.
4. 무엇을 어떤 방법으로 검증할지 정합니다. 문서 검토·디자인 검토·코드 검사·실제 동작 검증 중 이번 작업에 필요한 방법만 선택합니다.
5. 미정과 독립적으로 진행할 수 있는 범위를 구분하고, 후속 작업에 필요한 근거와 남은 판단을 정리합니다. 계획 작성만으로 실제 변경이나 외부 등록을 시작하지 않습니다.

## 받을 결과

목표·범위 / 현재 상태와 변경 계획 / 필요한 선택과 이유 / 선행 조건·관련 파트 / 완료·검증 기준 / 미정·미확인 사항 / 다음 작업을 정리합니다. 여러 작업에 걸친 계획은 지정된 업무 원본에 기록하고 공통 가이드에 실제 진행 상태를 복제하지 않습니다.


## 다음 작업과 기록

필요한 단계에서 시작합니다. 모든 스킬을 순서대로 실행하지 않습니다. 실제 결정·작업·이슈 상세는 지정된 원본에서 관리하고, 공통 가이드에는 복제하지 않습니다. 작업을 재개할 때는 이전 결과·미확인 사항·다음 작업부터 확인합니다.
