# 실제 프로젝트 개발 스킬 안내

서비스 구축을 위한 기획 검토·설계·소스 작성·검증·리뷰에 사용합니다. 파트별 상세 기준과 업무 스킬은 담당 PL이 관리합니다.

| 작업 | 스킬 | 받을 결과 |
| --- | --- | --- |
| 기획·요구 검토 | [lounge-grill](lounge-grill/SKILL.md) | 확인된 요구·결정할 질문·작업 영향 |
| 설계·작업 계획 | [lounge-spec](lounge-spec/SKILL.md) | 변경 계획·선행 조건·완료 기준 |
| 작성·수정·검증 | [lounge-implement](lounge-implement/SKILL.md) | 변경 결과·실제 검증·미확인 사항 |
| 결과 검토·인수인계 | [lounge-review](lounge-review/SKILL.md) | 수정할 항목·근거·다음 작업 |

필요한 단계에서 시작하고 모든 단계를 매번 실행하지 않습니다. 공통 가이드·브리핑 자체의 작성과 디자인 수정은 [가이드 작성 스킬](../guides/AGENTS.md)을 사용합니다.
