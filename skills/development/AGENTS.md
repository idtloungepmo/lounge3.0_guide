# 파트별 개발 스킬 선택 안내

실제 업무의 워크플로우와 스킬은 각 파트 PL이 구성하고 관리합니다. [파트별 워크플로우 구성 안내](../../collaboration/workflow.md)에 따라 프로젝트 공통 기준과 파트 업무에 맞는 원본 스킬을 연결합니다.

## 맷 포코크 원본 스킬

[Matt Pocock의 skills](https://github.com/mattpocock/skills)에서 필요한 스킬을 선택합니다. 요구 정리, 명세, 작업 분해, 구현·테스트·리뷰 등 이번 업무와 관련된 원문과 하위 스킬·참고 파일을 확인합니다. 원본 버전과 호출·연결 방법, 실제 기록 위치는 파트에서 관리합니다. 선택한 스킬이 이번 요청의 범위나 권한을 확대하지 않습니다.

## 기존 구성 참고본

이 폴더의 lounge-grill·lounge-spec·lounge-implement·lounge-review는 기존 작업 방법을 정리한 참고본입니다. 모든 파트의 기본 워크플로우나 필수 스킬로 지정하지 않습니다. 실제 사용할 스킬은 해당 파트 저장소의 안내를 확인합니다.

| 기존 참고본 | 담고 있는 역할 |
| --- | --- |
| [lounge-grill](lounge-grill/SKILL.md) | 기획·요구 검토 |
| [lounge-spec](lounge-spec/SKILL.md) | 설계·작업 계획 |
| [lounge-implement](lounge-implement/SKILL.md) | 작성·수정·검증 |
| [lounge-review](lounge-review/SKILL.md) | 결과 검토·인수인계 |

공통 가이드·브리핑 작성은 [가이드 작성 스킬](../guides/AGENTS.md)을 참고합니다. 필요한 지침만 선택하고 작은 수정에 전체 절차를 요구하지 않습니다.
