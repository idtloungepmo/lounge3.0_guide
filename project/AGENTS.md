# 프로젝트 공통 기준 관리 지침

- 프로젝트의 목적과 공통 관리 범위는 [프로젝트 안내](README.md)를 확인합니다.
- AI 작업 방식·문서 구조·공통 용어는 [공통 문서 운영 기준](documentation.md)을 따릅니다.
- 컨텍스트·컴팩션·상태 복원·원본 대조의 운영 규칙을 다루면 [AI 작업 가이드 심화](ai-context.md)를 확인합니다. 일반 작업에 기술 설명 전체를 필수로 읽히지 않습니다.
- 문서 추가와 수정은 [문서 관리 기준](maintenance.md)을 따릅니다.
- 파트 저장소 주소는 [저장소 안내](../README.md#저장소-안내)에 반영합니다. 개별 업무 자료 목록과 미정 저장 위치를 추측해 구성하지 않습니다. [자료 관리 기준](sources.md)은 자료 등록 시 필요한 항목만 안내합니다.
- 기획서·업무 기록과 공통 가이드의 역할을 구분합니다. 공통 가이드에 실제 정책·이슈 상세·진행 상태를 별도 확정본으로 복제하지 않습니다.
- 파트별 내용과 업무 절차·업무 스킬은 담당 PL이 관리합니다. 파트 간 변경은 [협업 지침](../collaboration/AGENTS.md)을 따릅니다.

- 하네스·가이드의 지침이나 구조를 변경하면 [문서 관리 기준](maintenance.md#하네스와-가이드-검증)에 따라 구조를 점검하고, 변경 영향에 맞는 대표 과제의 행동을 확인합니다. 수행하지 않은 행동 검증은 미확인으로 남깁니다.

## 공통 문서 자원 변경

이 절은 공통 CSS·JS·이미지 등 자원을 변경하는 요청에 적용합니다. 사용 방법은 [공통 문서 자원 안내](assets.md)를 확인합니다.

- assets/에는 스타일·스크립트·이미지·폰트 등 자원만 둡니다. 안내·관리 문서는 project/ 등 해당 문서 영역에 두고, 독립 다이어그램 HTML·구조 원본·갱신 안내는 diagrams/에서 관리합니다.
- 파일별 역할과 사용 방법은 [문서 자원 안내](assets.md)를 확인합니다.
- style/에는 CSS, js/에는 공통 동작을 둡니다. 이미지·아이콘·폰트는 실제 자료가 생길 때 필요한 폴더만 추가합니다.
- presentation-theme.css와 common.js는 공통 스타일과 동작을 관리합니다. 변경 전 사용하는 문서에 미치는 영향을 확인합니다.
- project-guide.css는 전체 시작 페이지에 사용합니다. document.css는 파트 시작 페이지와 개별 문서에 사용합니다.
- project-guide.js는 전체 시작 페이지의 요청문 복사 기능을 담당합니다. 개별 문서에 불필요하게 추가하지 않습니다.
- 공통 CSS·JS는 같은 원본을 사용합니다. 파트 전용 자원은 담당 PL이 관리하고 여러 파트에서 필요해지면 공통 사용을 협의합니다.
- 파트 색상은 [공통 색상 기준](part-colors.md)을 따릅니다. data-part와 CSS 변수·파일명은 유지합니다.
- 자원을 변경하면 관련 링크·키보드 조작·데스크톱·모바일·인쇄 결과를 가능한 범위에서 확인합니다. 확인하지 못한 범위는 표시합니다.

- HTML 발표에는 briefing-presentation.css와 briefing-presentation.js를 사용합니다. 발표 자원 변경은 [공용 브리핑 스킬](../skills/guides/html-presentation-design-system/SKILL.md)을 적용하고 장면 이동·반응형·인쇄 영향을 확인합니다.
