# 프로젝트 기본 정보

라운지 3.0은 기존 Android·iOS 앱을 Flutter 기반 하이브리드 앱으로 리뉴얼하고, 회원·결제 기능을 포함한 반응형 홈페이지를 구축하는 프로젝트입니다. 세부 기능과 정책은 기획에서 정합니다.

## 공통 관리 범위

기획·디자인·프론트엔드·백엔드는 문서 구조, 사람과 AI의 시작점, 공통 HTML 형식과 글쓰기 기준을 함께 사용합니다. 각 파트의 문서 내용·세부 절차·업무 스킬은 담당 PL이 관리합니다.

## AI 작업과 업무 원본

공통 가이드는 AI의 작업 방법과 문서 작성 기준을 제공합니다. 기획서와 향후 Redmine의 업무 기록은 각 원본에서 관리하며, AI는 관련 근거와 요청 범위를 확인한 뒤 작업합니다.
